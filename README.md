# EduEng by Greenfield

EduEng is an English language center management platform developed by **Công ty TNHH Công nghệ Greenfield** (Greenfield Technology), founded in Vietnam in 2023.

This repository contains a public product overview. The application source code is maintained separately in a private repository.

## What EduEng connects

- Admissions, learner records, enrollment and learning history.
- Classes, schedules and attendance.
- Tuition, payments and operating expenses.
- Exam creation, learner submissions, grading and reporting.
- Staff tasks, approvals and role-based operational workflows.
- Greenmind, an integrated AI assistant for information retrieval and workflow guidance within user access scopes.

## Product stage

EduEng is under active development, with plans to commercialize the product for language centers. Contact Greenfield to discuss a demonstration and deployment requirements.
